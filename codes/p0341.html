P0341 — Camshaft position sensor A circuit range/performance

OBD-II fault code · Crank, cam & timing · updated 2026-11-10 · English version is the reference

P0341 is the cam version of "the signal is there but I do not trust it". On engines with VVT this code is often about the oil control valve or a stretched chain, not the sensor.

What the code actually means

The camshaft sensor is producing pulses, but the pattern does not match what the ECU expects for the current crank position. It stores P0341 rather than P0340 because there is a signal — it is just implausible.

This is the code that shows up when a timing chain has stretched by a link's worth, when a VVT phaser is stuck, or when the cam sensor air gap is wrong. All three look identical on the scanner and completely different on the car.

What you will notice

  • A rattle at cold start on chain engines, followed by this code
  • Poor low-end torque and late or early cam timing on live data
  • Rough idle that improves with revs
  • P0011, P0016 or P0341 combinations
  • A hesitation when the VVT should advance

Test before you buy

  1. Watch commanded versus actual cam timing on live data while revving. A lag or a stuck value points at the phaser or the OCV, not the sensor.
  2. Remove and clean the oil control valve screen. If it is full of sludge, that is the fault.
  3. Check for a cold-start chain rattle before ordering any sensor.
  4. Compare the cam and crank signals if you have a scope — the offset tells you whether it is mechanical.

The expensive mistake

Selling a cam sensor for a stretched chain. The new sensor reports the same wrong pattern and the code returns within a week. Ask two questions first: does it rattle on cold start, and what is the commanded versus actual cam angle?

Questions we get

Does P0341 mean the sensor is bad?
Not usually. It means the signal is implausible. On VVT engines the cause is more often the oil control valve or the chain.
Can I drive with a P0341?
Yes, but do not leave it. If a chain is stretching, the next failure is a jump and a bent valve.
