# 部署说明（照着点就行）

目标：把 `型号查询站` 这个文件夹变成一条网址，客户点开就能查型号，Google 也能收录。
全程不用写代码，只有第 2 步的 Vercel 备选方案里有一条命令。

> **不想部署？** 直接发 `型号查询站-客户版.zip`（58 MB）给客户也行：解压后双击 `index.html` 就能离线查，
> 里面有 `START-HERE.txt` 中英双语说明。部署只是为了多一条“链接”和让 Google 收录。

---

## 第 0 步：确认域名（1 分钟）

1. 打开文件夹里的 **`站点设置.txt`**（用记事本打开），看 `域名=` 这一行。
2. 默认已经填好 `https://ymy-parts.pages.dev` —— 只要你按下面第 1 步把 Cloudflare 项目名取成 `ymy-parts`，**这一行不用改**。
3. 如果要用自己的域名（比如 `https://parts.yumengyang.com`），改成对应网址，保存后双击 **`更新数据.cmd`** 重跑一次。

> 为什么要在意：每个型号页里都写着"这个页面的正式网址"（canonical），还有分享到 Facebook / WhatsApp 时的缩略图地址（og:image）。域名填错，Google 会以为这些页面属于别人的网站。
> 如果域名还是占位符（`your-domain.com`），脚本会**故意不输出**这些标签——页面照样能用，只是分享没有缩略图、收录慢一点，不会指错地方。

改完可以双击 `index.html` 自查：随便搜个型号，点卡片右下角「独立页面 ↗」，能打开就说明正常。

---

## 第 1 步：上传到 Cloudflare Pages（推荐，免费、能拖拽）

1. 浏览器打开 **dash.cloudflare.com**，用邮箱注册一个账号（不用买域名、不用绑卡）。
2. 登录后，看左边菜单，点 **Workers & Pages**（中文界面叫「Workers 和 Pages」）。
3. 点右上角 **Create**（创建）→ 选上面的 **Pages** 标签 → 点 **Upload assets**（上传资源）。
4. 项目名字填 `ymy-parts`（这就是网址前缀，只能用小写字母和横杠），点 **Create project**。
5. 页面出现一个虚线框，把 **整个「型号查询站」文件夹** 拖进去。
   ⚠️ 拖的是**文件夹本身**，不是把里面的文件一个个拖出来。
6. 等文件传完（约 70 MB / 8,600 多个文件，看网速，几分钟），点 **Deploy site**。
7. 十几秒后出现网址，形如 `https://ymy-parts.pages.dev` —— 打开看看，能搜型号就成功了。

**以后改了数据怎么更新**：同样进 Workers & Pages → 点 `ymy-parts` → 右上 **Create new deployment** → 再拖一次文件夹 → Deploy。旧的会被替换，网址不变。

**想用自己的域名**（比如 `parts.yumengyang.com`）：进入这个 Pages 项目 → **Custom domains** → **Set up a custom domain** → 输入域名 → 按提示在 Cloudflare 里加一条 DNS 记录（它会自动帮你加）。生效后再把 `站点设置.txt` 里的域名改成这个，重新生成并再上传一次。

## 第 2 步：上传到 Vercel（备选，二选一就行）

Vercel 免费版也够用，但网页端要经过 GitHub，比 Cloudflare 多几步。**已经用 Cloudflare 的可以跳过这步。**

**方式 A：网页 + GitHub（不用命令行）**
1. 打开 **vercel.com**，用 GitHub 账号登录（没有就注册一个）。
2. 点 **Add New… → Project**。
3. 选 **Import Git Repository**，把装了这个站点的仓库选进来（需要先把文件夹传到 GitHub，网页上点 "uploading an existing file" 也能传）。
4. Framework Preset 选 **Other**，Build Command 留空，Output Directory 留空，点 **Deploy**。
5. 得到 `xxx.vercel.app` 网址。

**方式 B：一条命令（电脑装过 Node.js 才用）**
在 `型号查询站` 文件夹里，地址栏输入 `cmd` 回车打开黑窗口，粘贴这一条：

```
npx vercel --prod
```

按提示回车（一路默认），最后会给你网址。

## 第 3 步：让 Google 收录（Search Console）

> 不做这步，Google 也会自己慢慢发现；做了这步，通常快很多。

1. 打开 **search.google.com/search-console**，用 Google 账号登录。
2. 左上角点 **添加资源**，选 **网址前缀**（最简单），粘贴你的完整网址，比如 `https://ymy-parts.pages.dev/`。
3. 验证所有权：
   - 它会给你一个 **HTML 文件**（名字像 `google1234abcd.html`）→ 下载下来，放进 `型号查询站` 文件夹的**根目录**，跟 `index.html` 放一起，然后重新上传一次站点 → 回到 Search Console 点 **验证**。
   - 如果域名托管在 Cloudflare，也可以选 **DNS 记录** 验证，按提示加一条 TXT，通常 1 分钟生效。
4. 验证通过后，点左边 **站点地图**（Sitemaps）→ 在"添加新的站点地图"里填 `sitemap.xml` → 点 **提交**。
   - 显示"成功"就够了，不用管"已发现网页数"那一栏暂时是 0。
5. 点左边 **网页**（Pages），过 1–3 天会看到"已编入索引"的数字往上涨。

---

## 第 4 步：怎么知道真的被收录了

**方法一（最简单）**：在 Google 搜索框输入

```
site:ymy-parts.pages.dev
```

能看到你的页面，就是被收录了。数字会一天天变多。

**方法二（看单个页面）**：Search Console 顶部有个搜索框（"检查任何网址"），粘贴一个型号页地址，比如
`https://ymy-parts.pages.dev/c/90919-02248.html`
→ 回车。显示"网址已收录"就成功了；显示"已发现，尚未编入索引"就再等几天，或者点 **请求编入索引**。

**正常节奏**：首页和品类页 1–3 天；型号页 1–3 周开始出现，3500 多个页面全部收录一般要 4–8 周。这期间**不要反复改域名**。

## 常见问题

**Q：上传后打开是 404 / 一片空白？**
A：八成只传了 `index.html`。必须把整个文件夹传上去，里面要有 `c`、`category`、`assets`、`images`、`data` 这几个文件夹和 `sitemap.xml`、`robots.txt`。

**Q：页面能打开，但图片全是破的？**
A：`images` 文件夹没传全，或者传的时候被压缩软件改了小写/路径。重新拖一次整个文件夹。

**Q：部署好了，但分享到 WhatsApp / Facebook 没有缩略图？**
A：站点设置.txt 里的域名跟实际网址不一致。改成真实网址（带 https://）→ 双击 更新数据.cmd → 重新上传一次。没有实拍图的型号会自动用该品类的品牌卡片（ssets\og\）当缩略图。

**Q：Google 一直不收录？**
A：按顺序查三件事：① `站点设置.txt` 里的域名是不是真的改成了现在的网址并重新生成过；② Search Console 里 sitemap 是不是"成功"；③ 随便打开一个型号页，右键"查看网页源代码"，看 `<link rel="canonical">` 里的域名对不对。

**Q：改了 Excel 数据，怎么更新线上？**
A：双击 `更新数据.cmd` → 等跑完 → 重新上传一次文件夹（Cloudflare 是 Create new deployment）。网址不变。

**Q：能不能放在公司网站的子目录里（比如 yumengyang.com/parts/）？**
A：可以。站点内部全是相对路径，整个文件夹丢进子目录就能用。但 `站点设置.txt` 的域名要写成 `https://www.yumengyang.com/parts`，再重新生成一次。

**Q：free 的 pages.dev 域名会不会影响收录？**
A：不会，但收录慢一些、客户看着也不够正式。有条件就绑自己的域名。
