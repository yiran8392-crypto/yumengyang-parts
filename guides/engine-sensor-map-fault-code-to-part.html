Engine sensor map: which sensor sets which fault code

Published 2026-11-20 · 8 min read · English version is the reference

Buyers search by code, not by part name. This page turns a fault code into the sensor that sets it, then into the catalogue that sells it — with the one extra check that prevents a wrong order in each row.

How to use this page

Read the code, find the family in the table, then follow the link to the catalogue page or one of our guides. Every row also names the check that separates a failed sensor from a wiring or mechanical fault, because a code that names a sensor does not prove the sensor is faulty.

Codes in these ranges are generic OBD-II definitions; the same number can mean something else on a given manufacturer. Confirm against the maker's list before quoting a part.

The three pairs people confuse

  • MAP and MAF. Some engines use both, some only one. Fitting the wrong family leaves the engine management estimating air from a sensor that is not there.
  • TPS and accelerator pedal sensor. A drive-by-wire car has both; a P0120 is the throttle body, a P2135-style code can be either. Read which module reports the code.
  • Crank and cam. They fail with the same symptom on paper and completely different ones in practice: no crank signal means no start, no cam signal often still runs. See the no-start guide.

Codes that are not a sensor

Four families arrive in the same inbox and rarely need a sensor: P0420 (catalyst efficiency), P0442 and P0455 (evaporative leak), P0171 with a whistle (air leak), and P0300 with a compression problem. If the customer has already replaced two sensors for the same code, the code is describing an effect, not a part.
